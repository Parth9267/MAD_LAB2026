Aim

To test and review the Campus Connect Flutter application, configure an Android upload keystore, and
prepare the release signing and deployment workflow.

Theory

Flutter applications should be analysed and tested before deployment. Static analysis checks Dart code,
widget tests check interface behavior, and runtime testing examines the application on its target device. APK
files support Android installation, while Android App Bundles support store distribution.

Android release builds require a signing identity. A keystore holds the private key, key.properties supplies its
local configuration, and Gradle applies the release signing configuration. The key password and private key
must remain private.

Steps

1 Test the application Inspect available devices, run the application, and check form validation, Firebase save
and read actions, search, filtering, and deletion confirmation.

2 Debug and review Run flutter analyze and the setup widget test. Review the Android toolchain with flutter
doctor -v.

3 Create the upload keystore Generate an RSA upload key using keytool and inspect its certificate. Store the
password in the ignored local key.properties file.

4 Configure release signing Load key.properties in android/app/build.gradle.kts and assign the release signing
configuration to release builds.

5 Build and prepare deployment Generate and validate the release APK and App Bundle once the Android
toolchain is complete. Prepare the store listing and test on Android before publishing.
