                    EXPERIMENT 4

AIM: To create an interactive form in Flutter using the Form widget and input fields with validation.

OBJECTIVE: To understand how to create a form, accept user input, validate the entered data, and perform
an action when the form is submitted.

COURSE OUTCOME: Design and implement user interfaces using Flutter widgets, layouts, and animations,
ensuring responsiveness and interactivity

THEORY: The Form widget in Flutter is used to group and manage multiple input fields. It works with
widgets such as TextFormField to collect information from users. Form validation helps ensure that the
entered data is correct before submission. A GlobalKey<FormState> is commonly used to access and
validate the form. The validator property of TextFormField checks the input and displays an error
message when the entered data is invalid.

Software Requirements: -

      Flutter SDK
     Dart
     Android Studio / DartPad
     Web browser
