The ZIP includes the app source, rules and test. Platform scaffold folders must be generated as described in the project instructions. Firebase options are intentionally unconfigured; configure your Firebase project before using live student records. The report screenshots show the historical configured application, whereas this ZIP starts with a recoverable setup screen.
