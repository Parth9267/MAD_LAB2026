AIM: To design a Flutter user interface by using common Flutter widgets such as Text, Container, Row,
Column, Image, TextField, ElevatedButton, Icon, and Scaffold.

OBJECTIVE: To understand and implement commonly used Flutter widgets for creating an interactive
and user-friendly mobile application interface.

COURSE OUTCOME: Design and implement user interfaces using Flutter widgets, layouts, and
animations, ensuring responsiveness and interactivity.

THEORY: Flutter is an open-source UI framework developed by Google for creating cross-platform
mobile applications using the Dart programming language. Flutter uses widgets as the basic building
blocks of its user interface. Common widgets such as Scaffold, AppBar, Text, Container, Row, Column,
Icon, TextField, and Buttons are used to create and arrange different elements on the screen. Row arranges
widgets horizontally, while Column arranges them vertically. Container is used for styling and spacing, and
TextField accepts user input.
Flutter also provides Hot Reload, which allows developers to view code changes quickly without restarting
the entire application. Thus, common Flutter widgets can be combined to create a simple, interactive, and
user-friendly UI.
